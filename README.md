# Тренувальний бот для Telegram

Бот дозволяє:
- створювати план тренувань по днях (🆕 Новий день, ➕ Додати вправу)
- керувати планом — перейменувати або **видалити** вправу чи цілий день (🛠 Керувати вправами)
- переглядати план (📋 Мій план)
- записувати підходи: вага x повтори (📝 Записати підхід), з кнопкою "⬅️ Назад" на кожному кроці
- **швидкий запис наступних підходів**: після першого підходу зʼявляються кнопки "🔂 Такий самий підхід" (записує ту ж вагу й повтори в 1 тап — зручно для прямих підходів на кшталт 4×8) та "🔁 Ще підхід (N кг)" (та ж вага, тільки нові повтори)
- виправляти вже записаний підхід (вагу/повтори), якщо помилився — кнопка "✏️ Виправити цей підхід"
- бачити, що записано сьогодні (📅 Сьогодні)
- дивитись прогрес по вправі текстом **або графіком-картинкою** (📈 Прогрес → "📊 Показати графіком")
- **рекорди та 1ПМ** (🏆 Рекорди) — найважчий колись записаний підхід по вправі, автоматичний розрахунок одноповторного максимуму (1ПМ) за формулою Еплі, і рекомендовані ваги для легкого/середнього/важкого тренування (періодизація за NSCA)
- бот сам відмічає 🎉 новий рекорд одразу після запису, якщо підхід побив попередній максимум
- а якщо не рекорд, але краще ніж минулого тренування — бот напише 📈 "Це більше, ніж минулого разу!"
- **🎯 ціль на підхід** — перед тим як ввести вагу, бот сам підкаже: "Минулого разу було 60 кг x 8 — спробуй 62.5 кг x 8"
- **🔥 стрік тренувань** — лічильник днів поспіль із записаними підходами, показується в кінці тренування і в 📅 Сьогодні
- **📊 тижневий звіт** — підсумок за останні 7 днів: скільки тренувань, загальний тоннаж (вага × повтори), і які вправи прогресували найбільше порівняно з попереднім тижнем
- **прийняти подяку від користувачів** (☕ Подякувати автору) — оплата в Telegram Stars, без банківських карток чи платіжних провайдерів
- **⚖️ вага тіла** — окремий трекінг власної ваги з графіком динаміки
- **📤 експорт CSV** — вивантажити всю історію підходів у файл (відкривається в Excel/Google Таблицях)
- **📝 нотатки до тренування** — можна дописати коментар до дня ("боліло плече", "було важко") прямо в кінці `/log`
- **🖼 картки для шерингу** — красива картинка з рекордом чи тижневим звітом, яку зручно кинути в чат чи сторіз
- **🔔 нагадування** — якщо не тренувався 3+ дні, бот сам нагадає про себе (раз на кілька днів, без спаму)
- **📢 розсилка від власника** та **📊 статистика користувачів** — приховані команди лише для тебе
- користуватись постійним меню кнопок українською внизу екрана (замість набору команд руками; команди на кшталт /log теж працюють)

Усі дані зберігаються назавжди у файл `workout.db` (SQLite) поруч зі скриптом — бот памʼятає все між сеансами й перезапусками.

## Формули, які використовує бот

- **1ПМ (одноповторний максимум), формула Еплі:** `1ПМ = вага × (1 + повтори / 30)`
- **Періодизація навантажень (легкий / середній / важкий день),** за рекомендаціями NSCA (Essentials of Strength Training and Conditioning):
  - 🟢 Легкий день: **60% від 1ПМ**, 12–15 повторів
  - 🟡 Середній день: **75% від 1ПМ**, 8–10 повторів
  - 🔴 Важкий день: **85% від 1ПМ**, 3–5 повторів

  Це класична модель хвилеподібної (undulating) періодизації: чергування об'єму й інтенсивності в межах тижня дає кращий приріст сили, ніж однакове навантаження щоразу.

## Встановлення

1. Встанови Python 3.10+.
2. Постав залежності:
   ```
   pip install -r requirements.txt
   ```
3. Отримай токен бота:
   - Напиши в Telegram боту **@BotFather**
   - Команда `/newbot`, дай імʼя і username боту
   - Скопіюй токен, який тобі надішле BotFather (виглядає як `123456789:AA...`)
4. Встанови токен як змінну середовища:

   **Linux / macOS:**
   ```
   export TELEGRAM_BOT_TOKEN="твій_токен"
   python bot.py
   ```

   **Windows (PowerShell):**
   ```
   $env:TELEGRAM_BOT_TOKEN="твій_токен"
   python bot.py
   ```

5. Відкрий свого бота в Telegram і напиши `/start`.

## Як користуватись

1. `/newday` — створи день, наприклад «Ноги» або «Спина+біцепс».
2. `/addex` — додай вправи до цього дня (можна викликати кілька разів).
3. Під час тренування: `/log` → обери вправу → введи вагу → введи повтори. Бот запропонує додати ще підхід, виправити щойно записане, перейти до іншої вправи або завершити.
4. `/today` — подивитись усі підходи, записані сьогодні.
5. `/history` — обрати вправу і побачити найкращий підхід по кожному тренуванню текстом, або натиснути "📊 Показати графіком" для картинки.
6. `/records` — обрати вправу і побачити рекорд, розрахунковий 1ПМ і рекомендовані ваги для легкого/середнього/важкого тренування.
7. `/editex` — обрати день → перейменувати день, видалити його (з підтвердженням), або перейти до вправ дня → перейменувати/видалити конкретну вправу.
8. `/weekly` — тижневий звіт: тренування, тоннаж, прогрес.
9. `/bodyweight` — записати поточну вагу тіла (можна кілька разів на день — перезаписує сьогоднішній запис).
10. `/export` — отримати файл `workout_history.csv` з усією історією підходів.

## Нагадування, якщо давно не тренувався

Раз на день (о 9:00 UTC — тобто орієнтовно 11:00–12:00 за київським часом) бот перевіряє всіх користувачів і надсилає нагадування тим, хто не тренувався 3+ днів. Щоб не спамити, одному користувачу нагадування надсилається не частіше ніж раз на 3 дні. Це працює автоматично, нічого налаштовувати не треба — час 9:00 UTC зашитий у код (`dt_time(hour=9, minute=0)` у `main()`), зміни там, якщо хочеш інший час.

## Розсилка всім користувачам (лише для власника)

`/broadcast текст повідомлення` — надішле це повідомлення всім, хто хоч раз писав боту. Працює лише для `ADMIN_ID` (той самий, що для `/stats`), для решти користувачів команда просто нічого не робить.

## Скільки людей користується ботом

Telegram сам не показує кількість користувачів бота — тому бот рахує це сам:

1. Дізнайся свій Telegram user ID — напиши боту **@userinfobot**, він покаже число.
2. У Railway → Variables додай змінну `ADMIN_ID` зі своїм ID.
3. Напиши своєму боту `/stats` — покаже: всього користувачів, скільки активні за останні 7 днів, скільки всього тренувань записано.

Команда `/stats` працює лише для тебе (звіряється з `ADMIN_ID`) — для всіх інших вона просто нічого не робить.

## Донат від користувачів (Telegram Stars)

Кнопка "☕ Подякувати автору" запускає оплату у Зірках Telegram (валюта `XTR`) — не потрібен банк, картка чи платіжний провайдер, усе працює прямо всередині Telegram API.

- Зірки, які надсилають користувачі, накопичуються на балансі твого бота.
- Вивести їх можна в @BotFather → вибрати бота → **Bot Settings → Payments** → там же видно баланс і можливість конвертувати Зірки в Toncoin для виведення.
- Суми донату (20 / 50 / 100 / 250 ⭐) задаються в коді змінною `DONATE_AMOUNTS` — можна змінити на свій розсуд.

## Де тримати бота увімкненим

Поки скрипт `python bot.py` запущений — бот працює. Щоб він працював постійно, онлайн, найпростіше:
- залишити запущеним на своєму компʼютері/сервері (наприклад, через `screen` або `tmux` на Linux),
- або задеплоїти на безкоштовний хостинг на кшталт Railway, Render, або VPS.

## Розширення

Файл `bot.py` — один самодостатній файл, легко розширити далі:
- нагадування про тренування (по розкладу днів)
- прив'язка дня тижня до конкретного дня плану
- експорт історії в CSV/Excel
- порівняння прогресу з друзями
